Privacy Policy - Inkforge Uploader

Last updated: 13 November 2026

Inkforge Uploader is a private tool used only by the owner of the Inkforge YouTube channel (youtube.com/@InkforgeManhwa) to upload and schedule the channel's own videos through the YouTube Data API. It is not offered to the public.

What data it uses

With the channel owner's permission (Google OAuth), the tool uses the YouTube scopes needed to upload videos, set thumbnails and read the channel's own basic details. It does not access any other user's data.

How data is stored

The OAuth token is stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. Nothing is sent anywhere except to Google/YouTube APIs.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
